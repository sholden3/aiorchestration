# Applications Directory

## Purpose
Contains all application-level code including backend API, frontend web app, and desktop wrapper.

## Contents
- **api/** - FastAPI backend server with MCP governance integration
- **web/** - Angular frontend application
- **desktop/** - Electron desktop wrapper

## Dependencies
- Python 3.10+ for backend
- Node.js 18+ for frontend/desktop
- PostgreSQL 14+ (optional)
